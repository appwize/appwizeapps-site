# appwizeapps.com

Static site for Appwize LLC — app support and privacy pages, served by GitHub
Pages at [appwizeapps.com](https://appwizeapps.com).

| Path | Purpose |
|---|---|
| `index.html` | Landing page |
| `privacy.html` | Privacy policy for Wordly Word Search |
| `support.html` | Support page and FAQ |
| `app-ads.txt` | AdMob publisher authorisation — must stay at the domain root |

No build step. Plain HTML, edited in place.
